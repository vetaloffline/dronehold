# /start-work — свіжий main і нова гілка під задачу

Задача: `$ARGUMENTS`. Порожньо — спитати, яка задача (з неї буде назва гілки), і тільки тоді далі.

Команди `git` і `gh` — кожну окремим викликом, без `cd … &&`.

## 1. Де ми

```
git branch --show-current
git status --short
git fetch origin --prune
```

## 2. Незакомічені зміни

Нема — далі. Є — показати `git status --short` і спитати (AskUserQuestion), що з ними:

| Варіант | Коли пропонувати | Що робити |
|---|---|---|
| Стеш | не на `main` | `git stash push -u -m "<стара гілка>: перед <задача>"` |
| Коміт | не на `main` і PR гілки не `MERGED` (`gh pr view --json state`) | коміт на поточній гілці (заголовок англійською, як в історії) + `git push -u origin HEAD`; PR — це вже `/ship` |
| Перенести в нову гілку | завжди | нічого не робити: `git switch -c` забере зміни з собою |

На `main` стеш і коміт заблоковані хуком `guard-main.py` (на main — тільки читання, pull, fetch),
тому там лишається тільки «перенести» — сказати чому.

## 3. Свіжий main

- На `main`: `git pull --ff-only`
- Не на `main`: `git fetch origin main:main` (оновлює локальний main без переходу на нього; git
  відмовляє, якщо main не перемотується вперед).

Упало (локальний main має свої коміти) — показати помилку й **зупинитись**, нічого не форсувати.

## 4. Нова гілка

Назва `<тип>/<назва>`: тип — `feat` | `fix` | `docs` | `art` | `refactor` | `test`; назва — 2–4 англійські
слова через дефіс із задачі (`feat/relay-build-radius`, `art/slime-skins`).
Зайнята (`git rev-parse --verify --quiet refs/heads/<гілка>` або є на origin) — інша назва.

```
git switch -c <гілка> main
```

Перенос змін конфліктує зі свіжим main — git відмовить; показати помилку і спитати, що робити.

## 5. Прибрати змерджені гілки

Уже на новій гілці (на `main` хук забороняє `git branch -d`):

```
git branch --merged main
```

Кожну зі списку, крім `main` і нової гілки, — `git branch -d <гілка>`. `-d` видаляє тільки змерджене;
відмова — не форсувати, просто сказати.

## Звіт

Нова гілка, на якому коміті main (`git log -1 --oneline main`), що зроблено зі змінами (назва стешу й
`git stash pop`, щоб повернути), які гілки прибрано.
