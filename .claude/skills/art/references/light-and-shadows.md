# Світло і тіні

| Що | Хто робить | Як |
|---|---|---|
| Світлотінь на об'єкті | Codex | сонце справа вгорі, у промпті (стиль-блок) |
| Тінь нерухомої будівлі на землі | Codex | малює разом зі спрайтом; потім відділяється в `<назва>_shadow.png` |
| Тінь рухомих частин | код | проекція по шарнірах, напрям узгоджений з тінню Codex |
| Тінь юнітів | код | тінь-еліпс під кожним (`docs/concept.md`) |

**Як відділити тінь від спрайта:** тінь — це напівпрозорі темні пікселі (`alpha < 215` і
`r+g+b < 200`), решта — об'єкт. Під об'єктом тінь потрібно заповнити суцільно, інакше при зсуві
тіні лишається тільки контур. Приклад результату: `art/objects/buildings/core/`
(`core_shadow.png`, `core_shadow_cast.png`, `core_shadow_contact.png`, `core_with_shadow.png`).

**Напрям сонця для коду** береться з тіні Codex: на 1 px висоти точка зсувається на
`tx = -0.45` по X і `ty = +0.2` по Y (виміряно на корпусі бура).

**Не робити:** окрему генерацію «тільки тінь» — вона не збігається з силуетом.
