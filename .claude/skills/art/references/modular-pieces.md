# Модульні шматки, що стикуються (стіна)

Приклад — стіна (`art/objects/buildings/wall/`, апрув 2026-10-10). Журнал — `prompts.md` там же.

1. **Шаблон під клітинки**: `wall_template.py` → `wall_template.png` + `wall_template.json`
   (клітинка 32×24 ×8 = 256×192; стовп 136×104×150, проміжки висотою 110). Шаблон задає, де саме
   стоїть кожен шматок і якого він розміру.
2. **Один аркуш Codex з усіма шматками** (стовп, проміжок вліво-вправо, проміжок у глибину) за
   шаблоном + референс вигляду (`art/concept/12_wall_idea.png`).
3. **Збирач** `wall_assemble.py <аркуш> <тека>`: вирізає шматки біля їхніх блоків шаблону, підганяє
   точно під розмір блоку, складає тестові стіни (пряма, кут, сходинки, хрест, окремі) у превʼю
   `wall_assembled_preview.png` — по ньому видно, чи стикується.
4. У грі: `game/objects/wall/wall_rig.tres` (`pillar` / `along` / `depth`, точки на землі — з
   `wall_pieces.json`, ×0,125).

## Що вийшло з досвіду

- Спроба 1a: гарні шматки, але з перспективою (видно бічні грані) і не в розмір шаблону — не
  стикуються. Спроба 1b: Codex перемалював точно по шаблону — плоский фронт, стикується → апрув.
- Тобто для стикування важливіше точне попадання в шаблон, ніж «краса» окремого шматка; перевіряти
  збіркою, а не окремими шматками.
