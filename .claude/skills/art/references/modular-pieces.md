# Модульні шматки, що стикуються

Застосовувати, коли об'єкт складається з шматків, що мають стикуватися в різних комбінаціях (стіна).
Приклад: стіна — `art/objects/buildings/wall/` (апрув 2026-10-10), журнал — `prompts.md` там же.

## Кроки

1. Шаблон під клітинки: скрипт → `<назва>_template.png` + `<назва>_template.json` з позицією й розміром
   кожного шматка. Стіна: `wall_template.py`, клітинка 32×24 ×8 = 256×192, стовп 136×104×150, проміжки
   висотою 110.
2. Один аркуш Codex з усіма шматками (стіна: стовп, проміжок вліво-вправо, проміжок у глибину) за шаблоном +
   референс вигляду (стіна: `art/concept/12_wall_idea.png`).
3. Збирач `<назва>_assemble.py <аркуш> <тека>` (стіна: `wall_assemble.py`): вирізає шматки біля їхніх блоків
   шаблону, підганяє точно під розмір блоку, складає тестові комбінації (пряма, кут, сходинки, хрест,
   окремі) у `<назва>_assembled_preview.png`.
4. Перевіряти стикування по превʼю збірки, не по окремих шматках. Шматки не стикуються → спроба 2 з вимогою
   точно в шаблон.
5. У грі: rig (стіна: `game/objects/wall/wall_rig.tres`, шматки `pillar` / `along` / `depth`), точки на землі —
   з `<назва>_pieces.json` (стіна: `wall_pieces.json`, ×0,125).

## Досвід стіни

- Спроба 1a: гарні шматки, але з перспективою (видно бічні грані) і не в розмір шаблону — не стикуються.
- Спроба 1b: Codex перемалював точно по шаблону — плоский фронт, стикується → апрув.
- Висновок: точне попадання в шаблон важливіше за вигляд окремого шматка.
