# Будівля з рухомими частинами

Застосовувати, коли в будівлі є частина, що рухається відносно корпусу (рука бура з шарнірами).
Приклад у репо: бур — `art/objects/buildings/drill/` (корпус + рука з 3 сегментів, остання — лазерна голова),
сцена `game/objects/drill/`. Промінь, сяйво лінзи, розжарена пляма, іскри — кодом (групи `Beam`, `Lens`,
`Hot spot`, `Sparks` у `game/objects/drill/drill_rig.gd`).

## Кроки

1. Codex малює **зібраний** об'єкт: стиль, пропорції, шарніри видно чітко. → апрув людини (SKILL.md, крок 9).
2. Codex перемальовує його **розібраним**: кожна частина окремо з прозорими проміжками, у промпті
   «the same scale and rotation, only translated apart». Заховані місця (кінці шарнірів) домальовуються.
3. Вирізати частини заливкою по альфі. Злиплі частини → розрізати по шарніру; диск шарніра лишити верхній
   частині (тоді при обертанні на стику нема щілини).
4. Зняти центри шарнірів по збільшеній сітці.
5. Перевірка в Python: зібрані частини дають картинку кроку 1. Не дають → виправити крок 3–4.
6. Частина перемальована в іншому масштабі → підігнати за збігом силуету (IoU) зі старою.
7. Замінити одну частину → Codex перемальовує тільки її; місце кріплення (шарнір, хомут) взяти з оригіналу
   піксель у піксель і склеїти по шву.
8. Сцена в Godot: ланцюжок `Node2D` (корпус → суглоб 1 → суглоб 2 → суглоб 3), кожна частина обертається
   навколо свого pivot; анімація — `Tween` між позами + синус для вібрації. Параметри — у rig (таблиця нижче),
   людина крутить їх в Inspector.

## Файли

```

<назва>_assembled.png                       зібране превʼю з тінями
```

## Поля rig бура (`game/objects/drill/drill_rig.gd`)

| Поле | Що |
|---|---|
| `ground_point`, `map_scale`, `map_shift` | точка на землі в PNG, масштаб і зсув на карті |
| `shoulder_on_body` | точка кріплення першої частини на корпусі |
| `shoulder_ground` | точка на землі під кріпленням — для тіні |
| `seg1_pivot`, `seg1_end`, `seg2_pivot`, `seg2_end`, `seg3_pivot`, `seg3_lens` | шарнір кожної частини і її кінець, де кріпиться наступна (у голови — лінза) |
| `up_shoulder`, `up_elbow`, `up_head` | кути пози «піднято», градуси |
| `fire_shoulder`, `fire_elbow`, `fire_head` | кути пози «стріляє»; у слоті жили голова цілиться сама, `fire_head` — поправка |
| `t_move`, `t_charge`, `t_fire`, `t_cool`, `t_wait` | тривалість фаз, секунди |
| `recoil` | тремтіння при пострілі |
| `shadow_tx`, `shadow_ty`, `shadow_k`, `shadow_opacity`, `shadow_color` | тінь частин: зсув на 1 px висоти, товщина, прозорість, колір |
