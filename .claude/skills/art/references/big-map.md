# Велика карта без швів

Застосовувати, коли потрібна земля карти більша, ніж Codex малює за раз (≈5000 px).
Рецепт у коді: `art/maps/map_03/map_03_stitch.py`.

## Кроки

1. Схема рельєфу `map_NN_layout.png`: людина малює пензлем у редакторі земля / скеля / прірва. Це шаблон.
2. Codex малює **всю** карту за схемою в низькій роздільності — спільна основа тону і світла.
3. Основу збільшити й розрізати на 3×3 шматки з перекриттям ~25 %. Кожен шматок Codex деталізує окремо
   (референси: шматок основи + шматок схеми).
4. Склейка:
   - підігнати масштаб і зсув кожного шматка до основи;
   - tone lock: низькі частоти (колір, світло) — з основи, деталі — зі шматка (тон на стиках однаковий);
   - шов — по шляху мінімальної різниці (динамічне програмування) з м'яким переходом 60 px (скелі й дерева
     не двояться).
5. Перевірка: кропи кожного стику й кутів у збільшенні → людині.
6. Для гри: `map_NN_chunks.py` ріже землю на WebP ≤ 2048 px (телефон може не взяти текстуру 5K;
   27 МБ PNG → 4,3 МБ). У `map_NN_ground.png.import` — `importer="skip"`: сам великий PNG Godot не імпортує.
7. Сітка 32×24 перший раз заповнюється зі схеми: клітинка = «Скеля», якщо скеля чи прірва займає більше
   0.5 її площі. Далі типи клітинок розмічає людина вручну (`docs/concept.md`, «Карта і сітка»).
