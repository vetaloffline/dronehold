# Корисно знати

В цьому файлі описана корисна інформація для використання проекта

## Підтримка md файлів

--- Покращення роботи з проектом

```
Плагін - claude-md-management@claude-plugins-official 

1) /revise-claude-md - аналіз поточної сесії і виявлення проблем та оновлення документації
2) /claude-md-improver - аналіз md файлів проекті і пропозиції щодо покращення
```

### Корисно пам`ятати
--- Команда яка викличе кучу агентів для аналізу і роздасть кожному по невеликій частині роботи паралельно
```
/batch <prompt>
```

--- Команда яка зчитує актуальну інформацію по anthropic
```
/claude-api <prompt>
```

--- Команда запускає prompt з інтервалом кожні декілька хвилин чи годин
```
/loop 5m <якась команда чи промпт>
```

--- Команда для швидкого рев`ю тільки що змінених файлів (не знаходить баги а шукає неточності з проектом)
```
/simplify 
```

--- Команда для повноцінного review коду як на local, так і в репозиторіях
```
/code-review 
```

--- Скіл який допомагає створити протестованих і оптимізований скіл
```
/skill-crator <description>
```
